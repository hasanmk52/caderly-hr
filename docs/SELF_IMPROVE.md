# Self-Improvement Step

Only do this if something in this session is worth remembering: a bug that took
real effort to track down, an explicit correction from the user, or a decision
future sessions should know about. Skip it for routine, trouble-free work.

1. Write a short dated entry (2-4 sentences: what happened, why, what fixed it)
   and append it to LEARNINGS.log.
2. Do NOT edit CLAUDE.md directly.
3. Do NOT edit this file. Propose changes to it only if explicitly asked.

The user reviews LEARNINGS.log periodically and merges what's worth keeping into
CLAUDE.md by hand.
